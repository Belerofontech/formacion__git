Estándares de escritura de código

¿Por qué estandarizar?

Charla libre. Ideas a tocar: cualquiera puede leer/modificar el código de otra persona sin adaptarse a un estilo distinto, menos discusiones subjetivas en code review, errores más fáciles de detectar a simple vista.

Una lista — después


            def media(numeros: list[float]) -> float:
                """Devuelve la media de una lista de números."""
                return sum(numeros) / len(numeros)


            def maximo(numeros: list[float]) -> float:
                """Devuelve el valor máximo de una lista de números."""
                return max(numeros)
list[float]: tipo genérico de la librería estándar (desde Python 3.9), sin necesidad de importar typing.List.

Un DataFrame de polars — después


            def filtrar_mayores(
                df: pl.DataFrame, columna: str, umbral: float
            ) -> pl.DataFrame:
                """Filtra las filas donde una columna supera un umbral."""
                return df.filter(pl.col(columna) > umbral)


            def media_columna(df: pl.DataFrame, columna: str) -> float:
                """Calcula la media de una columna numérica."""
                return df[columna].mean()
El tipo viene de la propia librería (pl.DataFrame): el type hint no se limita a los tipos nativos de Python, funciona igual con tipos de terceros. Solución completa, con docstrings en formato Google, en practicas/estandares/si_da_tiempo/solucion/.

Logging

De print() a dejar constancia de qué hace el programa

print() es cómodo en local, pero no distingue gravedad, no dice de dónde viene el mensaje, y no se puede silenciar sin tocar el código. logging resuelve los tres problemas.

Niveles

DEBUG < INFO < WARNING < ERROR < CRITICAL

El nivel configurado es el umbral: con INFO, los mensajes DEBUG quedan silenciados sin borrarlos ni comentarlos.

Handlers


            import logging
            from logging.handlers import RotatingFileHandler

            logger = logging.getLogger(__name__)
            logger.setLevel(logging.INFO)

            stream_handler = logging.StreamHandler()
            file_handler = RotatingFileHandler(
                "app.log", maxBytes=1_000_000, backupCount=3
            )

            logger.addHandler(stream_handler)
            logger.addHandler(file_handler)
StreamHandler: a consola. RotatingFileHandler: a fichero, y al llegar a maxBytes lo rota en vez de crecer sin límite, conservando como mucho backupCount ficheros antiguos.
